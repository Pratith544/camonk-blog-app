# CA Monk – Blog Application

A modern blog application built as part of the CA Monk Frontend Interview Assignment.  
The app allows users to browse blogs, view detailed blog content, and create new blogs using a mock backend.

---

## Features

- View all blogs
- View blog details in a split-panel layout
- Create a new blog
- Light / Dark mode toggle
- Responsive UI
- Loading and error states handled gracefully

---

## Tech Stack

- React + TypeScript
- TanStack Query (server state management)
- Tailwind CSS (styling)
- shadcn/ui (UI components)
- JSON Server (mock backend)

---

## Setup Instructions

### Prerequisites
- Node.js (v18 or higher)
- Git

---

### Installation & Running the Project

1. **Clone the repository**
   ```bash
   git clone https://github.com/<your-username>/<your-repo-name>.git
   cd <your-repo-name>
2. **Install Dependencies**
   ```bash
   npm install

3. **Start the development server (in a new terminal)**
   ```bash
   npm run dev
The application will be available at:
http://localhost:5173

4. **Start the JSON Server (mock backend)**
  ```bash
   npm run server
